RESPOSTA CORRETA: D) 4
  y = a + b/x
  Ponto (-1, 0):  0 = a + b/(-1) = a - b      ->  b = a
  Ponto (2, 3):   3 = a + b/2  ->  3 = a + a/2 = 3a/2  ->  a = 2, b = 2
  a^b = 2^2 = 4
  Conferido no print: a assíntota tracejada mede y = 2 (= a). Confere com o
  que ele escreve no fim do quadro: 2^2 = 4.
