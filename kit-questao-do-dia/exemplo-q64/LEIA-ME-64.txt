RESPOSTA CORRETA: D) 225
  B está no eixo vertical com ordenada 5 -> f(0) = 5:
     (0 + 1)(0 + 0 + b) = 5 -> b = 5
  A está no eixo x com abscissa 1 -> f(1) = 0:
     (1 + 1)(1 + a + 5) = 0 -> 2(6 + a) = 0 -> a = -6
  f(4) = (4 + 1)(64 - 24 + 5) = 5 · 45 = 225. Confere com o quadro.
